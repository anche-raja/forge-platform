      Tests
      
    
      JUnit 5 + Mockito tests for the migrated classes in the output directory. Which classes is
      decided in code, and so is the destination; a test that fails a mechanical check, scores below the
      threshold, or runs and fails is staged instead of written — it never enters the build.
